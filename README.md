# FORGE Construction

Responsive construction landing page with a looping video hero and scroll animations.

## Preview

Open `index.html` in a browser or serve this folder with VS Code Live Server.

Keep the `assets` folder beside `index.html`.

## Notes

- The included hero video is 8 seconds long and loops muted.
- Reduced-motion users see the poster image.
- The contact form validates input but is not connected to a submission service.
